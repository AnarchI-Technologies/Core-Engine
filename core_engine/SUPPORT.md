# Support

AnarchI Core is currently in pre-release development.

## Community Support

Use GitHub issues for:

- Bug reports.
- Documentation problems.
- Feature requests.
- Packaging questions.
- Plugin manifest questions.

Do not post API keys, secrets, private logs, customer data, or security vulnerabilities in public issues.

## Security

Report security issues privately using `SECURITY.md`.

## Commercial Support

Commercial support, enterprise deployment, marketplace partnership, and plugin licensing terms are not yet finalized.

Contact: support@anarchi.local
