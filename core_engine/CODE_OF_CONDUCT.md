# Code of Conduct

## Standard

AnarchI Core expects direct, respectful, technically serious collaboration.

Participants should:

- Treat others with respect.
- Stay constructive during disagreement.
- Avoid harassment, threats, hate speech, doxxing, or personal attacks.
- Respect privacy, security boundaries, and confidentiality.
- Keep discussions focused on the project and its users.

## Enforcement

Project maintainers may moderate issues, discussions, pull requests, and repository access to protect the project and its contributors.

## Reporting

Report conduct concerns to: conduct@anarchi.local
