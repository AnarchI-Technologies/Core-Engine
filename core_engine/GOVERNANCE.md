# Governance

AnarchI Core is founder-led and proprietary source-available.

## Decision Making

Final product, licensing, security, marketplace, and release decisions are controlled by AnarchI.

Community input, pull requests, issues, and plugin proposals are welcome, but acceptance is discretionary.

## Maintainer Responsibilities

Maintainers are responsible for:

- Protecting the production readiness principle.
- Keeping the headless core independent from GUI packaging.
- Reviewing security-sensitive changes carefully.
- Avoiding premature production claims.
- Maintaining release notes and compatibility notes.

## Commercial Direction

The project is intended to support:

- A packaged standalone optimization product.
- A plugin marketplace.
- Headless integration into AnarkI zkEVM infrastructure.
- Agent-maintained optimization layers for AI and blockchain workloads.
