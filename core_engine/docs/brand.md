# Brand Notes

## Name

Company: AnarchI

Pronunciation: Anarchy

The spelling emphasizes the leading `A` and the final capital `I`, anchoring the company in AI-focused infrastructure while making the name look like a shortened protocol name.

## Core Terms

- Company: AnarchI
- Component: Core Engine
- Product wrapper: AnarchI Core is a working placeholder.
- Blockchain: name under discussion.
- zkEVM target: intended to use Immutable SDK.
- Existing DEK project name: Nexus, pending rebrand.

## Positioning

AnarchI builds AI infrastructure rooted in genesis daemon protocols: systems that let AI agents and humans comingle, strategize, socialize, plan, team up, and build businesses together.

The Core Engine is the physical-system optimization layer. It keeps machines running dense agent clusters from crashing, stalling, or starving for local and bridged resources.

## Visual Direction

- Dark operational surfaces.
- Blue for protocol/AI signal.
- Green for active health/resource recovery.
- Amber only for caution and risk.
- Avoid novelty sci-fi clutter. The system should feel like serious infrastructure.
